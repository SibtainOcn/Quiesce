# Guía: cómo añadir claves de traducción

Todas las cadenas de la interfaz de Quiesce viven en los archivos de idioma de
`locales/` y se referencian en el código con constantes tipadas generadas.

## Dónde están las traducciones

| Archivo | Rol |
|---|---|
| `locales/active.en.toml` | **Fuente de verdad** (inglés) |
| `locales/active.es.toml` | Traducción al español |

## Pasos para añadir una clave nueva

### 1. Añade la clave al archivo inglés (fuente de verdad)

`locales/active.en.toml`:

```toml
[settings.restore_defaults]
other = "Restore defaults"
```

### 2. Añade la misma clave al archivo español

`locales/active.es.toml`:

```toml
[settings.restore_defaults]
other = "Restaurar valores por defecto"
```

> ⚠️ La clave debe existir en **AMBOS** archivos. El validador falla si falta en alguno.

### 3. Regenera las constantes tipadas

```bash
go generate ./...
```

Esto actualiza `locales/keys_gen.go` con la constante `SettingsRestoreDefaults`
(el nombre se genera desde la clave: `settings.restore_defaults` → `SettingsRestoreDefaults`).

### 4. Valida que todo está completo

```bash
go run github.com/itskreisler/i18n-go/cmd/i18n validate -dir locales -default en
```

Debe imprimir `i18n validation passed`.

### 5. Usa la clave en el código

```go
fmt.Println(T(locales.SettingsRestoreDefaults))
```

## Formatos de mensaje

### Texto simple

```toml
[menu.this_will_clean]
other = "This will clean:"
```

### Con variables de plantilla

```toml
[clean.recycle_ok_freed]
other = "Recycle Bin emptied - {{.Size}} freed"
```

```go
TD(locales.CleanRecycleOkFreed, map[string]any{"Size": FormatBytesHuman(bytesFreed)})
```

### Con plurales (solo las formas que necesites)

```toml
[items]
one = "You have {{.Count}} item."
other = "You have {{.Count}} items."
```

```go
TP(locales.Items, 3, map[string]any{"Count": 3})
```

## Convenciones

- Nombra las claves en minúsculas, con puntos para agruparlas: `menu.*`,
  `clean.*`, `step.*`, `summary.*`, `ram.*`, `settings.*`.
- **No traduzcas**: los tags técnicos (`[OK]`, `[SKIP]`, `[WARN]`, `[ON]`,
  `[OFF]`), nombres de archivos, unidades (KB/MB/GB) ni comandos.
- Si el texto tiene partes con color (como `{{.Enter}}` en el menú), pasa la
  parte coloreada como dato de plantilla desde el código, no dentro del TOML.
- La primera lengua que se pasa a `New` es la preferida; la última es el
  fallback. Una clave ausente en el idioma preferido se resuelve desde el
  último idioma en lugar de fallar.
