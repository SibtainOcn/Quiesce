# Guide: how to add translation keys

All of Quiesce's UI strings live in the locale files under `locales/` and are
referenced in code with generated typed constants.

## Where the translations live

| File | Role |
|---|---|
| `locales/active.en.toml` | **Source of truth** (English) |
| `locales/active.es.toml` | Spanish translation |

## Steps to add a new key

### 1. Add the key to the English file (source of truth)

`locales/active.en.toml`:

```toml
[settings.restore_defaults]
other = "Restore defaults"
```

### 2. Add the same key to the Spanish file

`locales/active.es.toml`:

```toml
[settings.restore_defaults]
other = "Restaurar valores por defecto"
```

> ⚠️ The key must exist in **BOTH** files. The validator fails if it is missing from either.

### 3. Regenerate the typed constants

```bash
go generate ./...
```

This updates `locales/keys_gen.go` with the constant `SettingsRestoreDefaults`
(the name is derived from the key: `settings.restore_defaults` → `SettingsRestoreDefaults`).

### 4. Validate everything is complete

```bash
go run github.com/itskreisler/i18n-go/cmd/i18n validate -dir locales -default en
```

It should print `i18n validation passed`.

### 5. Use the key in code

```go
fmt.Println(T(locales.SettingsRestoreDefaults))
```

## Message formats

### Plain text

```toml
[menu.this_will_clean]
other = "This will clean:"
```

### Template variables

```toml
[clean.recycle_ok_freed]
other = "Recycle Bin emptied - {{.Size}} freed"
```

```go
TD(locales.CleanRecycleOkFreed, map[string]any{"Size": FormatBytesHuman(bytesFreed)})
```

### Plurals (only the forms you need)

```toml
[items]
one = "You have {{.Count}} item."
other = "You have {{.Count}} items."
```

```go
TP(locales.Items, 3, map[string]any{"Count": 3})
```

## Conventions

- Name keys in lowercase, using dots to group them: `menu.*`, `clean.*`,
  `step.*`, `summary.*`, `ram.*`, `settings.*`.
- **Do not translate**: technical tags (`[OK]`, `[SKIP]`, `[WARN]`, `[ON]`,
  `[OFF]`), file names, units (KB/MB/GB) or commands.
- If the text has colored parts (like `{{.Enter}}` in the menu), pass the
  colored part as template data from the code, not inside the TOML.
- The first language passed to `New` is the preferred one; the last one is the
  fallback. A key missing from the preferred language is resolved from the
  last language instead of failing.
