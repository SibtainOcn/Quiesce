Features

Twelve steps. You decide which run.

The safe ones are on. The ones that deserve a second thought stay off until you say so.

Your cleaning list

Tap a step to try it. In Quiesce you press F for settings, and your choices are saved.

Recycle Bin and Deep Cleanup start off. Deep Cleanup turns itself off again after one run.

Memory, actually freed

Four methods, run together with qc ram or one at a time. Quiesce shows how much came back.

ram-1Save pending changeson
ram-2Free cached memoryon
ram-3Free file cacheopt-in
ram-4Trim app memoryopt-in

Safe by default

Services paused for cleaning always start again, even if you close the window mid-run.

Checked before it runs

Installs and updates compare the file to the SHA-256 published on GitHub. A mismatch is deleted, not run.

SHA-256 matches SHA256SUMS.txtok

Easy in, easy out

Updates in one command. Leaves in one command too, taking its settings and PATH entry with it.

qc -uUpdate Quiesce
qc uninstallRemove it cleanly
Commands

Skip the menu.

Type what you want cleaned. Chain as many steps as you like. A typo is caught before anything runs, and your saved settings never change.

Run qc -h for every command.

qcOpen the menu
qc allClean with your saved settings
qc temp ramJust temp files and memory
qc temp-1 deep binAny mix, run in menu order
qc -uUpdate Quiesce
qc -vShow version and checksum
qc uninstallRemove Quiesce, its settings and PATH entry
Install

Installed in one paste.

No admin needed to install. Quiesce asks for it only when a clean needs it.

1

Open PowerShell

Press the Windows key, type PowerShell and press Enter.

2

Paste the line below

It downloads the latest release, checks its SHA-256 and sets up qc for any terminal.

3

Type qc

The menu opens. Press Enter to clean, or F for settings.

irm https://raw.githubusercontent.com/SibtainOcn/Quiesce/main/install.ps1 | iex
Prefer to do it by hand?Download qc-64bit.exe (or qc-32bit.exe for 32-bit Windows), check it with Get-FileHash .\qc-64bit.exe, then run it and say yes to installing. The only official source is the GitHub Releases page.
Changed your mind?Run qc uninstall. It closes any open Quiesce window, removes the program, your settings and logs, and takes its folder off your PATH. Nothing else is touched.
